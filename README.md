# FITX-Downloads · פיטאיקס

המאגר הרשמי של קובצי ההתקנה והעדכונים של **FITX**, אפליקציית כושר והרגלים בעברית.

[האתר הראשי](https://fitx-5r8.pages.dev/) · [פתיחת FITX](https://fitx-5r8.pages.dev/app) · [דף ההתקנות](https://fitx-5r8.pages.dev/downloads) · [תמיכה](https://fitx-5r8.pages.dev/support)

## התקנה בטלפון

- **Android:** פותחים את FITX ב־Chrome, בוחרים בתפריט ⋮ „התקנת אפליקציה” או „הוספה למסך הבית”, ומאשרים.
- **iPhone / iPad:** פותחים ב־Safari, לוחצים על שיתוף, בוחרים „הוספה למסך הבית” ואז „הוסף”.

## קובצי APK

APK חתום עדיין לא פורסם. כשגרסה מוכנה להתקנה תהיה זמינה, היא תופיע ב־[Releases](https://github.com/nitaydr1409/FITX-Downloads/releases) עם מספר גרסה והערות עדכון. עד אז אפשר להוסיף את האתר למסך הבית דרך הדפדפן.

## על FITX

FITX מרכזת יומן אוכל, אימונים, שתיית מים, סיכומים והתאמת דמות. היא מיועדת מגיל 13 ומעלה והממשק בעברית. ההתחברות וסנכרון הנתונים ממתינים לחיבור Supabase; מאמן Groq ממתין להגדרת מפתח ולחיבור החשבונות. התראות מחוץ לאפליקציה והקהילה עדיין בהכנה. התמיכה: **COMING SOON**.
