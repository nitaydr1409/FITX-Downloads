## מה כוללת FITX

יומן אוכל ואומדנים, אימונים, רישום מים, התקדמות, דמות אישית ומאמן AI. FITX מיועדת לגיל 13 ומעלה, עם התאמות לפי גיל. חיבור צעדים, קהילה, אישור אפוטרופוס, התראות Push ווידג׳טים ל־iPhone דורשים השלמה.
