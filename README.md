# FITX Downloads

המאגר הרשמי למדריכי התקנה ולקובצי גרסה של **FITX / פיטאיקס**.

[האתר הראשי](https://fitx-5r8.pages.dev/) · [כניסה ל־FITX](https://fitx-5r8.pages.dev/app) · [הוראות התקנה](https://fitx-5r8.pages.dev/app/downloads) · [תמיכה](https://fitx-5r8.pages.dev/support)

## התקנה בטלפון

**Android:** פתחו את האתר ב־Chrome, פתחו את תפריט ⋮ ובחרו „התקנת אפליקציה” או „הוספה למסך הבית”.

**iPhone / iPad:** פתחו את האתר ב־Safari, לחצו על שיתוף, בחרו „הוספה למסך הבית” ואז „הוסף”.

## Android APK

APK חתום עדיין לא פורסם. כשגרסה שניתן להתקין ולעדכן תהיה מוכנה, היא תופיע ב־[Releases](https://github.com/nitaydr1409/FITX-Downloads/releases) עם מספר גרסה והערות. הימנעו מקובצי APK ממקורות אחרים.

## חשבונות ו־AI

הנתונים נשמרים כרגע בדפדפן. הרשמה, כניסה וסנכרון ממתינים לפרויקט Supabase ולספק מיילים. המאמן מתחבר ל־Groq לאחר הגדרת מפתח `GROQ_API_KEY` כסוד ב־Cloudflare ו־Supabase לאימות. התראות דחיפה והקהילה עדיין אינן פעילות. תמיכה: COMING SOON.

FITX היא אפליקציית כושר והרגלים בעברית, מיועדת מגיל 13 ומעלה, וכוללת יומן אוכל ואימונים, רישומי מים, סיכומים והתאמת דמות.
