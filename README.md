## iPhone

ב־Safari פותחים את [FITX](https://fitx-5r8.pages.dev/app), לוחצים על **שיתוף** ואז **הוספה למסך הבית**. FITX מותאמת לפתיחה מהמסך הראשי כיישום רשת.

## מה כוללת FITX

יומן אוכל ואומדנים, אימונים, רישום מים, התקדמות, דמות אישית ומאמן AI. FITX מיועדת לגיל 13 ומעלה, עם התאמות לפי גיל. קישור אפוטרופוס, קבוצות/חברים, התראות Push וחיבור צעדים למערכת הבריאות עדיין בבנייה.
