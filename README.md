# FITX Downloads

המאגר הרשמי למדריכי התקנה ולקובצי גרסה של **FITX / פיטאיקס**.

[האתר הראשי](https://fitx-5r8.pages.dev/) · [כניסה ל־FITX](https://fitx-5r8.pages.dev/app) · [הוראות התקנה](https://fitx-5r8.pages.dev/app/downloads) · [תמיכה](https://fitx-5r8.pages.dev/support)

## התקנה בטלפון

**Android:** פתחו את האתר ב־Chrome, לחצו על תפריט ⋮ ובחרו „התקנת אפליקציה” או „הוספה למסך הבית”. אתר FITX מותאם למסך הטלפון ומותקן כקיצור דרך.

**iPhone / iPad:** פתחו את האתר ב־Safari, לחצו על שיתוף, בחרו „הוספה למסך הבית” ואז „הוסף”.

עדיין לא פורסם APK. כשגרסה חתומה ומוכנה לעדכונים תהיה זמינה, היא תופיע ב־[Releases](https://github.com/nitaydr1409/FITX-Downloads/releases) יחד עם מספר גרסה והערות. הימנעו מקובצי APK ממקורות אחרים.

## חשבונות והתקדמות

הנתונים נשמרים כרגע בדפדפן של המכשיר שבו השתמשתם. הרשמה, כניסה באימייל וסנכרון עדיין ממתינים לפרויקט Supabase ולספק שליחת מיילים. המאמן החכם, התראות דחיפה והקהילה עדיין אינם פעילים. תמיכה: COMING SOON.

FITX היא אפליקציית כושר והרגלים בעברית, מיועדת מגיל 13 ומעלה, ומאפשרת יומן אוכל ואימונים, מעקב מים, סיכומים והתאמת דמות.
