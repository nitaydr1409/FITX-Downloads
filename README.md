# FITX Downloads

המאגר הרשמי לקובצי ההתקנה והגרסאות של **FITX / פיטאיקס**.

## האתר והתקנה לטלפון

[פתיחת FITX](https://fitx-5r8.pages.dev/) · [הוראות התקנה והורדות](https://fitx-5r8.pages.dev/downloads)

אפשר להוסיף את האתר למסך הבית באנדרואיד דרך Chrome וב־iPhone דרך Safari. הנתונים כרגע נשמרים במכשיר שבו השתמשת.

## Android

קובץ APK יפורסם בעמוד [Releases](https://github.com/nitaydr1409/FITX-Downloads/releases) אחרי בניית גרסה חתומה שניתן לעדכן בבטחה. כרגע עדיין לא פורסם APK. אין להוריד קבצים ממקורות לא רשמיים.

## iPhone ו־iPad

אין קובץ התקנה לאייפון. כאשר אתר FITX זמין בכתובת HTTPS, פותחים אותו ב־Safari, לוחצים על שיתוף ובוחרים **הוספה למסך הבית**.

## גרסת אתר

אפשר להוסיף את FITX למסך הבית דרך Chrome באנדרואיד או Safari באייפון. הנתונים בגרסה הנוכחית נשמרים במכשיר ואינם מסתנכרנים בין מכשירים.

## פרסום עדכונים

קובצי התקנה רשמיים יופיעו ב־GitHub Releases עם מספר גרסה, תאריך, הערות עדכון ופרטי תאימות. כל עוד אין Release, אין APK להורדה.
